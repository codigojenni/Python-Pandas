# Python & Pandas Data Analysis

A collection of hands-on Python projects and exercises focused on **data analysis, data cleaning, manipulation, and visualization using Pandas**.

I created this repository while building my Python and data analysis skills through coursework and independent practice. Each project focuses on a different part of working with real-world datasets, from cleaning messy data to analyzing trends and creating visualizations.

## What I've Worked With

* **Python**
* **Pandas**
* **NumPy**
* **Matplotlib**
* DataFrames and Series
* Data cleaning and transformation
* Filtering and sorting data
* Grouping and aggregation
* Merging and joining datasets
* Pivot tables and data reshaping
* Statistical summaries
* Data visualization
* Identifying trends and outliers

## Projects & Analysis

### DataFrame Basics

Introduction to creating and working with Pandas DataFrames, including accessing data and performing basic operations.

### Data Selection & Filtering

Working with DataFrames to select specific columns and rows, filter information, and organize datasets.

### Data Analysis

Using Pandas to explore datasets, calculate statistics, and identify patterns within the data.

### Data Visualization

Creating visualizations to better understand and communicate information contained in datasets.

### GroupBy & Aggregation

Using grouping and aggregation techniques to summarize data and compare different categories.

### Data Transformation

Transforming and restructuring data to make it easier to analyze.

### Data Cleaning

Cleaning and preparing datasets by identifying inconsistencies, handling missing or messy information, and organizing data for analysis.

### Pivot Tables & Data Reshaping

Using pivot tables, melting, and stacking to reshape datasets and examine information from different perspectives.

### Sales Target Analysis

Combining sales and target data to evaluate performance and identify differences between actual results and goals.

### Monthly Sales Trends

Analyzing monthly sales data and creating visualizations to identify changes and trends over time.

### Advertising vs. Sales Analysis

Exploring the relationship between advertising budgets and sales revenue using data visualization.

### Customer Demographics Visualization

Visualizing customer demographic information to identify patterns across age groups and regions.

### Customer Spending & Outlier Analysis

Analyzing customer spending patterns and using visualizations to identify unusual values and potential outliers.
